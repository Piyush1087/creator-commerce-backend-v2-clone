# **Engineering Documentation: Phase 7 – Universal Wrapper Validation & Snapshot Archiving**

This final phase completes the surface orchestration pipeline. It establishes the programmatic type guardrails and data validation architecture required to ingest, verify, and permanently archive the structured output generated by **Prompt A (Brand DNA)**.  
Because LLM outputs can occasionally deviate from strict formatting rules, this phase implements automated Zod-based verification, recovery mechanics, and transactional persistence to post data securely to your AWS RDS PostgreSQL database.

## **2\. Data Modeling & Universal Wrapper Contracts**

Create the validation schema at /src/modules/intelligence/contracts/brand-dna-snapshot.schema.ts. This translates the markdown output contract defined in Phase 6 into programmatic type definitions that strictly govern the fields required by the Stitch UI templates.

import { z } from 'zod';

/\*\*  
 \* Provenance Evidence Component Schema  
 \*/  
export const EvidenceSchema \= z.object({  
  page\_url: z.string().url('Evidence citation must be a valid URL string'),  
  page\_type: z.string().min(1, 'Page type taxonomy identifier is required'),  
  excerpt: z.string().min(1, 'Textual proof citation string cannot be empty'),  
});

/\*\*  
 \* Reusable Universal Field Wrapper Factory   
 \* Enforces metadata constraints across every discrete entity property  
 \*/  
export function createUniversalWrapper\<T extends z.ZodTypeAny\>(valueSchema: T) {  
  return z.object({  
    value: valueSchema,  
    confidence: z.number().int().min(0).max(100),  
    evidence: z.array(EvidenceSchema).min(1, 'At least one verified citation source is required'),  
    source: z.enum(\['AI', 'USER', 'SYSTEM'\]),  
    edited: z.boolean().default(false),  
  });  
}

/\*\*  
 \* Target Audience Persona Nested Structure  
 \*/  
export const AudiencePersonaSchema \= z.object({  
  name: createUniversalWrapper(z.string().min(1)),  
  age\_range: createUniversalWrapper(z.string().min(1)),  
  gender: createUniversalWrapper(z.string().min(1)),  
  geography: createUniversalWrapper(z.string().min(1)),  
  affluence\_score: createUniversalWrapper(z.string().min(1)),  
  traits: createUniversalWrapper(z.array(z.string())),  
});

/\*\*  
 \* Authoritative Validation Contract for Prompt A (Brand DNA)  
 \*/  
export const BrandDnaSnapshotSchema \= z.object({  
  industry\_niche: createUniversalWrapper(z.string().min(1)),  
  tone\_of\_voice: createUniversalWrapper(z.array(z.string())),  
  audience\_personas: z.array(AudiencePersonaSchema).min(1, 'At least one specific target consumer persona must be identified'),  
});

export type BrandDnaSnapshot \= z.infer\<typeof BrandDnaSnapshotSchema\>;

## **4\. Implementation Blueprint (NestJS Components)**

Create the validator and archiving manager module at /src/modules/intelligence/services/snapshot-validation.service.ts. This service wraps structural ingestion inside a retry execution boundary, maps fields cleanly, and writes data to AWS RDS.  
TypeScript  
import { Injectable, Logger, UnprocessableEntityException } from '@nestjs/common';  
import { InjectRepository } from '@nestjs/typeorm';  
import { Repository } from 'typeorm';  
import { ScanEntity } from '../../scan-engine/entities/scan.entity';  
import { BrandDnaSnapshotSchema, BrandDnaSnapshot } from '../contracts/brand-dna-snapshot.schema';

@Injectable()  
export class SnapshotValidationService {  
  private readonly logger \= new Logger(SnapshotValidationService.name);

  constructor(  
    @InjectRepository(ScanEntity)  
    private readonly scanRepository: Repository\<ScanEntity\>,  
    // Inject the extraction engine service to issue corrective retries if required  
    private readonly brandDnaEngine: any   
  ) {}

  /\*\*  
   \* Main entry point to validate incoming payload and archive structured snapshots  
   \*/  
  async validateAndArchive(scanId: string, rawJson: any, currentRetryCount \= 0): Promise\<BrandDnaSnapshot\> {  
    this.logger.log(\`Executing Universal Wrapper validation for Scan ID: ${scanId} | Execution Round: ${currentRetryCount}\`);

    // Unpack root node helper block if LLM nests the schema under 'brand\_dna' wrapper key  
    const targetPayload \= rawJson?.brand\_dna ? rawJson.brand\_dna : rawJson;

    // Execute absolute safe runtime type-check  
    const result \= BrandDnaSnapshotSchema.safeParse(targetPayload);

    if (result.success) {  
      this.logger.log(\`Structural Zod validation passed completely for Scan ID: ${scanId}. Archiving snapshot record.\`);  
        
      // Persist the clean, validated snapshot data to the database ledger  
      await this.scanRepository.update(scanId, {  
        brand\_dna\_verified\_snapshot: result.data,  
        current\_stage: 'STAGE\_2\_BRAND\_DNA\_ARCHIVED',  
        updated\_at: new Date(),  
      });

      return result.data;  
    }

    // Capture validation errors for troubleshooting  
    const validationErrors \= result.error.format();  
    this.logger.warn(\`Snapshot formatting violation occurred on Scan ID: ${scanId}. Errors: ${JSON.stringify(validationErrors)}\`);

    // Fault-tolerant recovery loop: Issue automated retries up to 2 times  
    if (currentRetryCount \< 2) {  
      this.logger.log(\`Initiating automated correction loop for Scan ID: ${scanId}. Current Try Count: ${currentRetryCount \+ 1}\`);  
        
      try {  
        // Re-execute extraction engine pass, passing down error metrics to adapt prompt logic if desired  
        const freshRawJson \= await this.brandDnaEngine.extractBrandDna(scanId);  
        return await this.validateAndArchive(scanId, freshRawJson, currentRetryCount \+ 1);  
      } catch (retryError) {  
        this.logger.error(\`Automated processing retry step failed: ${retryError.message}\`);  
      }  
    }

    // Fallback path when errors persist across multiple attempts  
    this.logger.error(\`Critical formatting validation failed for Scan ID: ${scanId} after maximum execution steps.\`);  
      
    await this.scanRepository.update(scanId, {  
      current\_stage: 'STAGE\_2\_NEEDS\_REVIEW',  
      error\_logs: \`Universal Wrapper Validation Failure: ${JSON.stringify(validationErrors)}\`,  
      updated\_at: new Date(),  
    });

    throw new UnprocessableEntityException('Generated data schema structure broke universal structural wrapper contracts.');  
  }  
}

## **5\. Fault Isolation & Recovery Routines**

To maintain resilience across serverless AWS container runtimes, implement these strict operational guards:

### **Case A: Malformed Citation Array Boundaries (Empty Evidence Logs)**

* **Indication:** Gemini outputs data values accurately but drops citation anchors, returning an empty evidence: \[\] array wrapper block.  
* **Resolution Pattern:** The Zod engine detects the .min(1) boundary breach and flags success: false. The validation service intercepts this structural failure and schedules a retry invocation.  
* **Correction Prompt Injection:** During the automated retry loop, append an execution string parameter to the prompt compiler stating: *"Your previous response failed structural parsing contracts because data parameters were missing clear page citations. You must provide a valid* page\_url *and* excerpt *context match for every single attribute property."*

### **Case B: Partial Schema Mappings (Truncated Context Output)**

* **Indication:** The LLM runs out of execution tokens halfway through, returning an unclosed or incomplete JSON block ("audience\_personas": \[ { "name": "Minimalist Persona"...).  
* **Resolution Pattern:** The baseline standard JSON.parse sequence inside the BrandDnaEngineService throws a native runtime processing error before reaching the Zod verification service. The try/catch block intercepts the error, writes the tracking logs to the database instance, and tags the row status as STAGE\_2\_BRAND\_DNA\_FAILED to prevent downstream system lockups.
