8. ERROR / RECOVERY BEHAVIOR
==================================================

Use the G0.2C frozen matrix.

400 / INPUT VALIDATION

- keep current hydrated context;
- preserve user draft where applicable;
- allow correction/retry;
- no DTO/debug wording.

401 / SESSION

- do not fabricate Collaboration state;
- hand off to established auth/session behavior;
- no token/JWT information.

403 / UNSUPPORTED ACTION

- retain hydrated read state;
- action becomes unavailable after authoritative refresh where appropriate;
- use Product-facing action-unavailable behavior.

404 / COLLABORATION UNAVAILABLE

Use frozen copy:

Headline:
Collaboration unavailable

Body:
This collaboration may no longer be available or you may not have access.

Action:
Back to Collaborations

Do not enumerate ownership.

409 / STALE

- one authoritative refresh;
- retain usable data;
- allow retry only against refreshed state;
- no aggregateVersion/commandId UI.

5XX / NETWORK FAILURE

- retain last good data where available;
- show pane-local failure;
- expose Retry or Refresh;
- no server/internal names.

MALFORMED READ

- use G1A contract-failure path;
- never render guessed canonical state.

MESSAGE SEND FAILURE

- keep conversation history;
- keep user's draft where practical;
- unlock composer after failure;
- allow explicit retry.
