5. DEEP-LINK INTEGRITY
==================================================

Canonical query parameter for new links:

?thread=<collaborationId>

Continue accepting legacy:

?collaboration=<collaborationId>

but normalize newly-created links to `thread`.

When a URL contains a requested Collaboration ID:

DO NOT determine validity from membership in the current inbox list.

Resolve the requested detail directly.

Cases:

Owned valid Collaboration:
→ show requested Collaboration

Missing Collaboration:
→ unavailable state

Existing but unauthorized Collaboration:
→ same unavailable state

Collaboration absent from first inbox page/filter:
→ still resolve detail correctly if owned

Invalid/no-access state copy:

Headline:
Collaboration unavailable

Body:
This collaboration may no longer be available or you may not have access.

Action:
Back to Collaborations

Never reveal whether another user owns the Collaboration.

on Inbox.
