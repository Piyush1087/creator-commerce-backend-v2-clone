D. Runtime read validation

frontend read-schema layer is required.

publishingRequired.

E. Legacy compatibility

- when projectionSource=LEGACY_COMPATIBILITY can actually occur;
- which canonical fields may be absent;
- whether such rows are expected for production migration only;
- what the frontend can safely render;
- what must be unavailable;
- how canonical and compatibility data remain distinguishable without
  exposing debug terminology to users.

Do not invent a migration-removal date.

F. Environment

Collaboration.

- Brand vs Creator role;
- owned vs invalid deep link;
- canonical vs invalid read model;
- lifecycle capability rendering;
- stale aggregate/refetch;
- legacy compatibility row;
- terminal state;
- realtime degraded state;
- per-Deliverable Publishing behavior.

Do not add a test framework during G0.2.
Only recommend the minimum implementation consistent with the existing
repository.
