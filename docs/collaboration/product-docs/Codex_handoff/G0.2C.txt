7. REALTIME DEGRADED POLICY
==================================================

Persisted HTTP remains authority.

Determine the smallest robust MVP behavior when Socket.IO is disconnected.

Preferred functional direction:

- keep already-hydrated state usable;
- clearly indicate live updates are temporarily unavailable;
- provide manual Refresh;
- allow safe HTTP reads/actions where backend permits;
- after reconnect, refetch authoritative detail/messages;
- never reconstruct workflow state from socket history.

Investigate whether bounded fallback polling is necessary.

Do not add polling merely because realtime is disconnected if manual refresh +
reconnect-refetch is sufficient.

Return a recommendation with reasoning.
