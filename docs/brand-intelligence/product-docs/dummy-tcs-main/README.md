# Creator Shop — Intelligence Architecture

This repository is the working implementation reference for the Creator Shop Intelligence Platform.

## Structure

- `intelligence/` — intelligence architecture, engines, branches, processors, execution profiles and artifacts.
- `backend/` — focused view of existing backend fields touched by intelligence plus new backend fields introduced while building the intelligence system.

## Working rule

Documentation follows the implemented intelligence architecture, not historical document names. Older concepts such as IBS/BDR/PDR/IOR/ISR are retained only where they represent a real runtime or metadata responsibility.

The `{identity}` branch of Brand Intelligence is the first reference implementation. Once frozen, its structure will be replicated across other branches and engines.
