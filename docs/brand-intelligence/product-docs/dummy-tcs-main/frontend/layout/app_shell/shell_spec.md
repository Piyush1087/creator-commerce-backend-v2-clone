# Application Shell Specification

## Desktop
Persistent:
- Sidebar
- Header
- Global navigation
- User menu
- Notifications

## Mobile
Persistent:
- Header
- Bottom navigation
- Hamburger menu

## Shell responsibilities
Owns:
- Navigation
- Branding
- Notifications
- User menu
- Content container

Does not own:
- Campaign UI
- Brand Centre UI
- Marketplace UI
- Drawers
- Feature modals

Every feature module renders inside the Content Area.
