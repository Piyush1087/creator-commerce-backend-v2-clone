# Canonical Campaign Asset migration constraint

`UceCampaignAsset` selects exactly one Brand Centre entity. Prisma's nullable
compound uniqueness constraints prevent duplicate selections but do not enforce
the exactly-one-reference invariant or consistency with `kind`.

The reviewed PostgreSQL migration must add a CHECK equivalent to:

```sql
CHECK (
  (kind = 'BRAND' AND brand_profile_id IS NOT NULL AND offering_id IS NULL AND brand_offer_id IS NULL)
  OR
  (kind = 'OFFERING' AND brand_profile_id IS NULL AND offering_id IS NOT NULL AND brand_offer_id IS NULL)
  OR
  (kind = 'OFFER' AND brand_profile_id IS NULL AND offering_id IS NULL AND brand_offer_id IS NOT NULL)
)
```

Do not apply this constraint until legacy Product-to-Asset mappings and candidate
rows have been reviewed and backfilled. No database migration is generated by
the static consolidation pass.
